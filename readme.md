# Mini Jarvis 🤖

### A Step Toward Making Technology Accessible to Everyone

Mini Jarvis is an AI-powered assistant project designed to make digital services
easier to access through natural language conversations.

The idea is simple: people should not need to understand English, navigate
complicated interfaces, or learn multiple applications just to perform everyday
digital tasks.

Mini Jarvis aims to make technology more accessible through conversational
interaction, with a focus on Indian languages and practical everyday use cases.

## 🎯 Vision

Build a conversational AI assistant that helps users interact with digital
services in a simple, natural, and accessible way.

The long-term vision is to help users perform tasks such as:

- 🎫 Exploring and booking travel tickets
- 🎬 Finding and booking movie tickets
- 💳 Accessing digital payment services
- 🧾 Managing bill payments
- 🗣️ Interacting in Indian languages, including conversational Telugu

These are intended use cases. Actual booking and payment integrations depend
on future development and the availability of supported services.

## ✨ Current Project

Mini Jarvis is under development.

The project currently includes:

- A Python-based backend.
- A FastAPI application.
- An LLM integration using the OpenAI API.
- A frontend application.
- A conversational assistant workflow under development.

The exact capabilities may evolve as the project develops.
